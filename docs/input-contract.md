# 原始资料契约

所有机构、车辆、单据和设备均为本地合成，不来自新闻中的真实企业，也不声称新闻发生过这些事件。

inputs/versions.json声明S1与S2的源文件集合，文件都已存在；current指针可改变，但固定版本不可偷偷换文件。完全相同的行是合法重复。可由输出之外的源行位置作为最终并列决胜依据，必须固定并可解释，不能借去重消除并列；同一会话重取必须逐字节稳定。
请求声明投影、筛选、排序方向及NULLS FIRST/LAST，sort字段不一定输出。chunk_rows是行数上限，block_digest校验块原始字节，数据格式可由实现选择并在会话固定；确认仅记录客户端已确认，不断言未确认块未抵达。续领凭证应绑定会话、固定查询及位置并能验证被篡改或误用。
来源演练时间由调用者提供，expires_at是绝对演练秒，达到即到期；不得通过改宿主时钟让测试等待真实分钟。显式取消立即禁止后续领取。memory_mib包括生成结果与合并缓冲，temp_bytes包括未清理失败导出；空间不足不得写出可领取的残缺结果。回收只能删除无当前仓引用且无合法领取保留的文件，结束会话不自动删除当前仓数据。
大样本可用 python -m materials.generate --out /tmp/export-input --rows 200000 生成，多分片重复/NULL排序值保留；该工具只生成输入，不排序、不生成领取块。

seed.json与同名Parquet保存相同的输入值，actions.json中的后续动作尚未处理。inventory.json只校验原件物理完整性，不是仓库目录或业务结论。所有后续仓表与接口均待开发，源码不规定其架构。
